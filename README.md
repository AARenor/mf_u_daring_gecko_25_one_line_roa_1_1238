# One-line gadget roast

This repository holds a program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a Python 3.13 script, standard library only and no network, that emits a single original line roasting a gadget or app used every day.

The entry text, 83 characters, written with no trailing newline:

```text
My watch congratulated me on a twelve-hour stand goal I hit standing at the fridge.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`; it creates the folder, writes `entry.txt` there and prints the character count to stderr.
